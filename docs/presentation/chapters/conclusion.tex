\section{Conclusion}
    \begin{frame}{Conclusion}
        \begin{itemize}
            \item Both the MPI and hybrid implementations exhibit excellent efficiency and weak scalability.
            \item As $K$ and $D$ increase, communication overhead becomes more significant, negatively impacting MPI performance.
            \item The hybrid approach effectively utilizes multi-core architectures, reducing communication overhead.
            \item Performance is consistent with the state-of-the-art literature.
        \end{itemize}
